# Profil Steam — Carte HTML Sémantique

Une maquette de carte de profil inspirée de **Steam** (**LordR0gue4**, niveau **42**, basé à **Dijon, France**), construite avec des balises **HTML5 sémantiques** tout en conservant les classes CSS pour la mise en page (`style.css`).

## Fonctionnalités et sections

- **En-tête du profil (`<header>`)** : avatar, pseudo, logo Steam, localisation (`<address>`) et niveau Steam.
- **Activité actuelle (`<section>` / `<article>`)** : affichage du jeu en cours et d'un statut personnalisé.
- **Vitrine de badges (`<section>` / `<ul>`)** : liste des badges mis en avant (*Année de service*, *Collectionneur*, *Vétéran CS*).
